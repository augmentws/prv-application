title: Viewing documents
description: Open email and plain-text collection items safely in the built-in viewer.
---

## Open an item

1. Open a client and collection.
2. Find the item in the collection table.
3. Select **Open**.

For an email, the viewer displays common headers and the readable message body. For a text file, it displays the text content. Content is shown as text rather than executed as active HTML.

## Download the native file

Use the download action in the viewer when you need the original native artifact or when its format is not supported by the built-in viewer.

## Current limitations

The built-in viewer is intentionally small. It currently supports EML/email and plain-text content. Office documents, PDFs, images, audio, video, spreadsheets, archives, and other binary formats require download or a future specialized viewer.

Items are opened from client collections. Matter-level document review is not yet implemented.
