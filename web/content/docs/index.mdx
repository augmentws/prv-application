## What is available now

The current application supports local password sign-in, hierarchical tenants, users, clients, matters, automatic default matter metadata definitions and groups, custom fields and groups, personal visibility preferences, reusable matter templates, configuration cloning, client-level evidence collections, imported collection items, custodians, native artifact viewing for email and text, durable jobs that link collection documents into matters, matter-level chunk and embedding generation, named topic clustering, manual review coding, and the agent-assisted Matter Definition workflow.

Root administrators can manage reusable system agents. Tenant-agent management screens, general corpus-processing workflows, review-platform integrations, production workflows, and cross-matter agent monitoring are not yet available in the user interface.
